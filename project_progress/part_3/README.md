## Project Progress – Part 3

## Notebooks
- **Part_1.ipynb**: Initial experiments/setup for the project. Open and run cells top-to-bottom.
- **Part2_Word2Vec+Cosine.ipynb**: Retrieval using Word2Vec embeddings with cosine similarity; includes loading data, building/using embeddings, and evaluating results.

## Quick start
1. Install Jupyter (any option is fine):

```bash
pip install notebook    # or: pip install jupyterlab
```

2. Launch Jupyter from this folder:

```bash
jupyter notebook        # or: jupyter lab
```

3. Open and run the notebooks (Kernel → Restart & Run All is recommended):
   - Run `Part_1.ipynb`
   - Then run `Part2_Word2Vec+Cosine.ipynb`
